Desarrollado en java con Open oracle jdk 25.0.2 Build: Maven Language level: SDK defaul

Ejercicio asignado 7: Sistema de reserva de servicios. 
Consiste en desarrollar una aplicación para registrar clientes, servicios y reservas. 
Cada reserva debe tener un identificador único, fecha, tipo de servicio, cliente y nivel de prioridad. El sistema debe permitir evitar duplicidades, buscar reservas por código, 
mantener determinados datos ordenados y procesar solicitudes especiales antes que las normales.
